Como se instala

Dos lineas dentro de Claude Code. Sin descargar carpetas, sin tocar nada oculto.

# 1. Le dices donde queda la caja de herramientas
/plugin marketplace add Dasvoia/dasvo-ia-builders

# 2. La abres
/plugin install dasvo@dasvo-ia-builders

# 3. Las despiertas
/reload-plugins

Despues escribe / y deben salir trece que empiezan con dasvo. Si salen, terminaste. Empieza por /dasvo:setup-cuentas.

Necesitas Claude Code instalado y una cuenta de pago de Claude (Pro, Max, Team o Enterprise). El plan gratis no lo incluye.

El mapa

Las cuatro fases se recorren una sola vez por cliente.

Tu semana 1

Marca cada dia. Se guarda mientras la pestana este abierta.

La trampa del dia 3

Casi todo el mundo se queda puliendo el sistema y nunca llega al dia 5. El sistema no paga: el mensaje enviado paga. Si el dia 4 no tienes un link vivo, congela el sistema como esta y sigue igual. Un sistema al 80 por ciento enviado le gana a uno perfecto guardado.

Los numeros

Precios de Vercel y Supabase verificados en julio de 2026. Verificalos antes de cotizar: cambian.

Antes de usar esto con un cliente real

  • Verifica los precios. Vercel y Supabase cambian sus planes. Los de este paquete son de julio de 2026.
  • Vercel Hobby no permite uso comercial. El sitio de un cliente que paga va en Vercel Pro. Sin excepciones.
  • Supabase Free pausa el proyecto tras una semana sin actividad. Sirve para practicar y para la demo. Nunca para produccion.
  • Los rangos del embudo son expectativas de trabajo, no estadisticas de un estudio. Reemplazalos con tus propios numeros despues de 30 mensajes enviados.
  • El modelo de precios es un modelo de mercado, no una promesa de ingresos.
  • Los terminos contractuales y tributarios varian por pais. Revisa los tuyos con un contador o abogado local antes de firmar.
  • Corre siempre /seguridad-web antes de entregar, publicar o grabar pantalla.
